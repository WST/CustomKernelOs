# Lua 5.4.8 через ext

`ext install lua` клонирует тег `v5.4.8` и собирает интерпретатор компилятором
`cc` внутри MyOS. Если `git` ещё не стоит, рецепт сначала ставит порт `git`.

```sh
ext install lua
lua
```

Программа оказывается в `/ext/bin/lua`. Сборка идёт с `-DLUA_USE_C89`:
разбор шестнадцатеричных дробей свой, вызовы POSIX не используются.
Makefile берётся из каталога порта и подменяет штатный.

`ext uninstall lua` удаляет установленные файлы порта.

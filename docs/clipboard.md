# Буфер обмена и выделение текста

Буфер общий для программ MyOS, хранит до 64 КиБ текста в оперативной памяти
и сохраняется после закрытия программы-источника. После перезагрузки он пуст.
Получить содержимое может только тот UID, который его записал. С Windows
буфер автоматически не синхронизируется.

## Блокнот

- Выделение мышью или Shift + стрелки / Home / End / PgUp / PgDn.
- Ctrl+A — выделить документ.
- Ctrl+C / Ctrl+X / Ctrl+V — копировать / вырезать / вставить.
- Ввод заменяет выделение; Backspace и Delete удаляют его.
- Поддерживаются многострочный текст, кириллица, CRLF и CR.
  Tab при вставке превращается в четыре пробела.
- Текущий редактор принимает UTF-8 в пределах BMP. Некорректный UTF-8 и
  символы за пределами BMP отклоняются без удаления выделенного текста.

## Терминал

- Выделение видимого текста мышью, включая несколько строк.
- Ctrl+Shift+C — копировать; Ctrl+Shift+V или Shift+Insert — вставить.
- Ctrl+C по-прежнему передаётся программе как прерывание.
- Концевые пробелы строк при копировании убираются. Новый вывод и изменение
  размера снимают выделение. Истории прокрутки пока нет.
- Вставляемые переводы строк передаются как Enter и могут выполнить команды.
  Управляющие байты, кроме Enter и Tab, отбрасываются.
  Текст передаётся небольшими порциями; набор клавиш отменяет остаток вставки.

## Браузер

- Текст страницы выделяется перетаскиванием мыши; Ctrl+C копирует выделение,
  Ctrl+A выделяет текст страницы. Обычный щелчок по ссылке работает при
  отпускании кнопки. Повторная раскладка страницы снимает выделение.
- В адресной строке и полях форм: Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V.
  Вставка в однострочное поле останавливается перед управляющим символом.
- При копировании страницы используются текстовые элементы раскладки;
  между строками добавляются переводы строк. HTML и изображения не копируются.

## API и проверки

`clipboard_set(text, length)` и `clipboard_get(text, capacity)` объявлены
в `myos.h`. Нулевой байт не добавляется. `clipboard_get(NULL, 0)` возвращает
размер; недостаточная ёмкость даёт `-EFBIG` без частичной записи.
Предел — `CLIPBOARD_MAX`. Ошибки возвращаются как отрицательные errno.
Системный вызов добавлен в конец таблицы без изменения прежних номеров.

Клавиши с Shift передаются консолью через внутренние CSI-последовательности
`ESC [ a` … `ESC [ j`; `k` и `l` означают Ctrl+Shift+C/V. `readkey` возвращает
`KEY_SHIFT | KEY_*`, `KEY_COPY`, `KEY_PASTE`. Это протокол MyOS, не xterm.

В WSL из каталога проекта:

```
make clipboardtest
make browsertest
```

Первый тест загружает MyOS в QEMU на копии диска, проверяет системный вызов,
реальный код Блокнота/Терминала и нажатия клавиш. Затем отдельный запуск
проверяет настоящий рабочий стол и окно Блокнота: выделение Shift+стрелками,
копирование, вставку и сохранение результата; снимок выделения остаётся в
`build/clipboard-notepad-selection.ppm`. Второй target проверяет браузер
с ASan/UBSan, включая копирование страницы, адреса и поля формы.

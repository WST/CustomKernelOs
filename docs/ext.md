# Сторонние программы

Команды самой системы лежат в `/bin`. Порты чужих программ ставятся в `/ext`
и запускаются из `/ext/bin`. Если имя совпало, оболочка выполняет файл из `/bin`;
копию из порта запускают полным путём `/ext/bin/имя`. Дополнение по Tab смотрит
в оба каталога.

```sh
ext list
ext install lua
ext uninstall lua
```

Порт — каталог `/ext/instructions/<имя>/`. Имя каталога и есть имя порта.

- `setup.inst` ставит порт;
- `uninstall.inst` снимает его; зависимости при этом остаются;
- остальные файлы каталога — патчи и заготовки вроде `config.h`.

В рецепте одна команда на строку. `#` до конца строки — комментарий.

| Команда | Действие |
|---|---|
| `name <id>` | имя порта |
| `descr <текст>` | короткое описание |
| `workdir <путь>` | создать каталог и перейти в него |
| `mkdir <путь>` | создать каталог, в том числе вложенный |
| `depend <имя>` | сначала поставить этот порт, если его ещё нет |
| `fetch [-r N] <url> [куда]` | скачать через `/bin/download`; без `-r` два повтора |
| `git <аргументы>` | `/ext/bin/git` или `/bin/git`; если файла нет, сначала ставится порт `git` |
| `tar <аргументы>` | `/bin/tar`, в том числе `xzf` для `.tar.gz` |
| `make [аргументы]` | `/bin/make` |
| `cc <аргументы>` | компилятор системы |
| `copy <файл> <куда>` | файл из каталога порта в дерево сборки |
| `patch [-p N] <файл>` | unified diff из каталога порта, по умолчанию `-p1` |
| `rm <путь>` | удалить файл |
| `rm -r <путь>` | удалить файл или каталог целиком |

Поставленный порт отмечается в `/ext/installed/<имя>`. Порт с отметкой
пропускается и при прямом запросе, и как зависимость. Цикл зависимостей —
ошибка. Отметка снимается только после успешного `uninstall.inst`.

Список для нового Live-образа и команды `ext auto` описаны в
[автоустановке](ext-autoinstall.md).

## Порты

| Порт | Что ставится |
|---|---|
| [lua](lua.md) | Lua 5.4.8 |
| [openssh](openssh.md) | OpenSSH 10.6p2, клиент и `sshd` |
| [nano](nano.md) | GNU nano 9.3 |
| bash | Bash 5.3 |
| git | Git 2.47.0 |
| grep | `grep` из sbase |

`wget` и `download` системы ходят в HTTPS через уже собранные libcurl и OpenSSL.
Это библиотеки образа, а не порты `ext`: [как они подключены](libcurl.md).

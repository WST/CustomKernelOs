# USB hotplug и хабы

Аппаратная Live-сборка поддерживает подключение и отключение USB-клавиатур и
мышей без перезагрузки через один xHCI-контроллер. Контроллер запускается и
с пустыми портами: клавиатуру можно подключить после появления приглашения входа.
Состояние корневых портов и портов хабов проверяется фоновым USB worker.

Поддерживаются USB 1.x/2.x хабы, включая вложенные, и USB2-часть комбинированных
USB3-хабов. Программируются route string, root port и TT slot/port для устройств
низкой/полной скорости за high-speed хабом. Хабы используют default single-TT
alternate setting; порты включаются и сбрасываются через hub-class requests.
Максимум 32 устройства, 64 HID-интерфейса, 5 уровней route string и 15 портов
на поддерживаемый хаб. SuperSpeed-only хабы пока показываются без class driver.

```sh
lsusb
lsusb -t
lsports
```

`lsusb` показывает актуальные VID/PID, класс и логический путь через хабы.
Путь `5.3.1` — корневой порт 5, затем порт 3 и порт 1 на хабах.
`lsports` сохраняет список корневых USB/SATA-портов. Нумерация не обязана совпадать
с подписями на корпусе. Новый `HWINFO_USB_DEVICE` добавлен как отдельный вид
записи: размер прежнего `HWINFO_USB` и номера системных вызовов не изменены.

## Отключение и повторное подключение

Сначала снимаются нажатые клавиши, модификаторы, повтор и кнопки мыши.
При нескольких USB-клавиатурах/мышах учитываются нажатия остальных устройств.
Поддерево отключается от дочерних устройств к хабу. Только успешный Disable Slot
позволяет очистить DCBAA и освободить DMA-страницы, transfer rings и контексты.
После этого записи и память можно использовать для новых подключений.
При невозможности подтвердить остановку DMA память остаётся в карантине,
контроллер останавливается и PCI bus mastering отключается.

Необязательный control request со STALL сбрасывает EP0 и его dequeue pointer
перед продолжением работы. Обычная ошибка/отключение устройства не должны
останавливать ввод с остальных устройств. Тайм-аут command ring считается
неисправностью контроллера; его восстановление без перезагрузки пока отсутствует.

Флешки и другие неподдержанные классы заново определяются и видны в `lsusb`,
но USB Mass Storage/BOT/SCSI и чтение/монтирование данных с флешек ещё не
реализованы. Автоматического монтирования или форматирования нет.

## Проверки

`make usbhotplugtest` создаёт отдельный Live-образ и запускает QEMU с 4 CPU
без PS/2. Проверяются пустой контроллер, подключение клавиатуры после загрузки,
нажатая кнопка при отключении мыши, 40 переподключений без роста расхода памяти,
хабы/вложенные хабы, удаление поддерева, отпускание Shift, замена клавиатуры и
появление/удаление флешки в диагностике. `make usblifecycletest` моделирует
DMA-барьер Disable Slot, отказ остановки, освобождение страниц, агрегацию ввода,
TT route и переходы колец. Пользовательские disk.img и Live-образ не изменяются.

Интерфейсы: Intel xHCI 1.2, разделы 4.3/4.5/6.2/6.4;
USB 2.0, глава 11 (hub-class requests).

# Панель управления

Отдельное оконное приложение `/bin/settings`: запуск командой `settings`,
через список приложений или пункт Settings в системном меню рабочего стола.

* **Сеть**: eth0, MAC, IPv4, маска, шлюз, DHCP/static, счётчики пакетов и смена DNS.
  DNS применяется сразу через существующий API ядра, до перезагрузки.
  Смена IP, управление DHCP и отключение адаптера пока не поддерживаются API.
* **Рабочий стол**: выберите одну из шести миниатюр — обои применятся сразу. Для своего изображения введите абсолютный путь в файловой системе MyOS
  и нажмите «Установить». PNG, JPEG, GIF (первый кадр), BMP; файл до 8 МиБ.
  Изображение проверяется декодером перед сохранением. Обои заполняют экран,
  сохраняя пропорции и обрезаясь по центру. Прозрачность смешивается с тёмным фоном.
  «По умолчанию» возвращает Луну. Без сохранённого выбора рабочий стол использует Луну.
* **Экран**: текущий видеодрайвер, разрешение и аппаратный курсор;
  кнопка запускает существующее приложение Display.
* **Система**: время работы, подсказка переключения языка, запуск диспетчера
  задач, терминала и сведений о системе.

Щёлкните поле для ввода; Tab переключает фокус поля, Enter применяет DNS или обои,
Escape закрывает панель. Стрелки вверх/вниз переключают разделы, когда поле не в фокусе. Путь к обоям сохраняется в `/etc/wallpaper`.
Рабочий стол перечитывает его по сообщению `WM_WALLPAPER = 113`, при запуске
и при смене разрешения. Если файл исчез или испорчен, используется встроенный фон.
Для сохранения обоев нужны права на запись `/etc/wallpaper`.

Сборка: `make build/user/settings build/user/desktop`; установка: `make install`.

Проверка: `make settingstest` — QEMU с отдельным временным диском: смена DNS,
сохранение обоев, переключение всех шести JPEG и проверка пикселей рабочего стола.

Стрелки влево/вправо в разделе рабочего стола выбирают обои, если поле не в фокусе.
Ctrl+U очищает поле ввода. Стандартные изображения находятся в `/usr/share/wallpapers`.

Новые образы создаются размером 16 МиБ. Старый образ можно перенести без изменения
исходника: `python3 tools/resize_myfs.py disk.img build/larger.img 16`, затем
`make install DISK=build/larger.img`. Перед переносом остановите QEMU.

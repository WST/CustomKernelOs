# Совместимость сайтов: проверка 6 ноября 2026

Добавлены AbortController/AbortSignal (reason, throwIfAborted, abort, timeout,
any), EventTarget и DOMException. Request сохраняет signal при копировании.
fetch отклоняет уже отменённые запросы и отменяет запрос, ожидающий запуска
в очереди таймеров. Синхронный нативный сетевой вызов пока нельзя прервать
из JavaScript во время его выполнения.

Response.blob/arrayBuffer возвращают соответствующие объекты, clone сохраняет
данные, повторное чтение использованного тела отклоняется. Добавлены базовые
TreeWalker/NodeIterator и NodeFilter. Element.animate возвращает объект с
таймингом, ready/finished и управлением состоянием: это совместимый жизненный
цикл, а не полноценная отрисовка Web Animations. CSS transforms и визуальная
интерполяция ключевых кадров пока не реализованы.

Исправлена flex-раскладка с анонимным текстовым элементом: число цены больше
не накладывается на соседний блок руб/мес. Слишком большой HTTP-ответ теперь
отклоняется с причиной вместо передачи обрезанного JavaScript парсеру.

Проверки: make jstest, make browsertest (ASan/UBSan),
python3 tests/browser_smoke.py. Последний тест запускает настоящую MyOS в QEMU
на копии диска и проверяет сеть, модули, async generators, AbortSignal и Response.

Для проверки реальных сайтов добавлен тестовый режим:

```
build/browser-host --net https://mkpnet.ru/ timers 5000 w 1280 shot build/mkp.ppm
build/browser-host --net https://juicyvps.ru/ timers 1500 w 1280 at 650 shot build/juicy.ppm
```

Он выполняет настоящие DOM/JS/CSS/раскладку браузера с сетевым транспортом curl
на хосте; это не проверка TLS и сетевого стека MyOS на этих сайтах.
В основной сборке этот транспорт отсутствует.

mkpnet.ru: приложение создаёт содержимое главной страницы, меню, карточки и
обращается к API; прежние ошибки Blob/AbortController/animate устранены.
juicyvps.ru: главная страница, карточки тарифов, загрузка скриптов и стили;
проверки навигации по всему сайту и личного кабинета не проводились.

YouTube: устранён первый блокер createTreeWalker, но остаются ограничения
Web Components и размеров ресурсов. Его основной JS-бандл превысил даже
8-МиБ лимит диагностического DOM-хоста и был обрезан; такой результат нельзя
считать свидетельством синтаксической несовместимости полного бандла.
В основном браузере предел одного ответа — 2 МиБ. Декодеров видео, аудио
и Media Source Extensions нет. Полной работоспособности YouTube не достигнуто.

Другие ограничения: SVG, Grid, CSS positioning, полная семантика ES modules,
Web Animations и DOM traversal поддерживаются не полностью. Эти изменения
не означают полной совместимости со всеми современными сайтами.

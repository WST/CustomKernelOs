# GNU nano через ext

Порт GNU nano 9.3 собирается внутри MyOS штатными `cc` и `make`.
Войдите под root, настройте сеть и выполните:

```sh
ext install nano
nano /root/example.txt
```

Редактор устанавливается в `/ext/bin/nano`, лицензия — в
`/ext/share/nano/COPYING`. `ext uninstall nano` удаляет эти файлы, сохраняя
ваши документы. Повторная установка уже установленного пакета пропускается.

Основные клавиши:

- Ctrl+O, Enter — сохранить файл;
- Ctrl+X — выйти (для изменённого файла появится вопрос о сохранении);
- Ctrl+W — поиск;
- Ctrl+K / Ctrl+U — вырезать строку / вставить;
- Alt+U / Alt+E — отменить / повторить;
- Ctrl+G — справка.

Обозначение `^` в подсказках означает Ctrl, `M-` — Alt. Вместо Alt можно
нажать Esc, затем нужную букву. `nano -l file` включает номера строк.
Поддерживаются несколько открытых буферов и редактирование UTF-8, включая
кириллицу. Для корректного отображения символов нужен шрифт терминала с
соответствующими глифами. Редактор работает в консоли и через SSH с PTY:

```sh
ssh -t root@192.168.2.2 nano /root/example.txt
```

Для автоматической установки в новый Live-образ добавьте пакет в `.env`:

```dotenv
EXT_AUTOINSTALL_PACKAGES="openssh nano"
```

В установленной системе можно выполнить `ext auto add nano`.
[Подробности автоустановки](ext-autoinstall.md). Live-корень находится в RAM;
установка пакета и документы исчезают при перезагрузке, если их не сохранить
на постоянном носителе.

## Профиль порта

Используются оригинальные исходники GNU nano 9.3 из
[официального архива GNU](https://ftp.gnu.org/gnu/nano/nano-9.3.tar.gz).
Приватный слой в `ext/instructions/nano` предоставляет нужную редактору
часть curses через ANSI, UTF-8 и адаптацию POSIX API к MyOS. Полная ncurses,
база terminfo и GNU configure не требуются. Экран хранится в памяти;
в терминал отправляются изменившиеся участки. Размер PTY проверяется при
чтении клавиш; после изменения размера редактор перестраивает экран.
При выходе восстанавливается исходный режим терминала.

Первый профиль не включает подсветку синтаксиса, nanorc, переводы интерфейса,
мышь, файловый браузер и внешние инструменты. Выполнение внешних команд
и приостановка через Ctrl+Z явно отклоняются. Асинхронные обработчики
сигналов не поддерживаются: автоматическое аварийное сохранение при kill
или обрыве SSH не гарантируется. `fsync` и перенос временных меток
резервной копии недоступны; сохранение использует обычный файловый ввод-вывод
MyOS. Unicode-классификация и ширина символов реализуют ограниченный набор,
а не полные таблицы Unicode.

## Проверки

`make nano-build` проверяет SHA256 архива и компилирует исходники тем же
MyOS cc на хосте. `make nanotest` устанавливает пакет настоящим `ext`
в отдельном QEMU-образе: распаковка, патч, нативная сборка, запуск в консоли,
UTF-8, сохранение и повторное открытие, поиск, undo, вырезание/вставка,
изменение размера PTY, повторная установка и удаление.
`make nano-networktest` выполняет тот же сценарий с настоящим HTTPS-скачиванием
архива внутри MyOS и сверяет несколько распакованных исходников с проверенным
архивом хостовой сборки.
`make nano-sshtest` дополнительно проверяет редактирование и сохранение
через настоящий SSH-сеанс, изменение размера его PTY и существующие проверки OpenSSH.
Офлайн-тест установки заранее кладёт проверенный архив в тестовый диск;
сетевое скачивание в этой проверке заменяется, остальные команды рецепта
исполняются без изменений.

# Колесо мыши

PS/2-драйвер включает IntelliMouse (4-байтные пакеты); обычные мыши продолжают
работать с 3-байтными пакетами. `mouse_get` возвращает накопительный `wheel`:
положительное направление — вверх. Старый формат системного вызова сохранён.

Рабочий стол отправляет `EV_MOUSE_WHEEL` окну под указателем, только над его
клиентской областью, не меняя фокус. `e.x/y` — координаты внутри окна,
`e.wheel` — число шагов со знаком. Во время захвата мыши колесо игнорируется.

Браузер прокручивается на 48 пикселей за шаг; Проводник, Блокнот и Code — на
3 строки. В Code колесо над деревом прокручивает дерево отдельно от текста.
Курсор редактора остаётся на месте.

Терминал хранит до 1000 строк вывода и прокручивает их по 3 строки.
Новый вывод сохраняет положение просмотра до вытеснения самых старых строк.
Ввод с клавиатуры возвращает к текущему выводу; копирование сохраняет просмотр.
Изменение размеров окна очищает историю. Частичные области ANSI в историю
не попадают. При нехватке памяти терминал продолжает работать без истории.

USB-мышь пока использует HID boot protocol: колесо USB этим изменением не поддерживается.

Проверки: `python3 tests/wheel_smoke.py` проверяет PS/2 в QEMU (с временным
слоем записи дисков). `tests/terminal_history.c` проверяет кольцевую историю,
сохранение позиции и изменение размеров.

# PR #2: исправления и проверки

Исправления объединены с буфером обмена. Номер SYS_CLIPBOARD сохранён;
новые SYS_LSEEK, SYS_FSTAT и SYS_RENAME идут после него в обеих таблицах.

- Новый rename проверяет защищённую базу аккаунтов и каталог /etc под общей
  блокировкой пространства имён. Проверки работают и с относительными путями,
  и с компонентами . и ... Обычные перемещения файлов остаются доступны.
- HTTP переводит POSIX-ошибку read из errno в собственный формат -errno.
  TLS проверяет errno == ETIMEDOUT и продолжает вызывать обработчик ожидания.
- download записывает ответ в уникальный временный файл рядом с назначением.
  Ошибки URL/HTTP/TLS, обрыв передачи и несовпадение Content-Length сохраняют
  прежний файл. После успешной передачи существующий файл переносится в
  резервное имя, затем публикуется новый. При ошибке публикации прежнее имя
  восстанавливается; если восстановление невозможно, выводится путь резервной
  копии. Эта последовательность не является атомарной заменой: при аварийном
  завершении между переименованиями может потребоваться восстановить имя
  по оставшейся резервной копии.
- gzip сравнивает нормализованные пути до открытия назначения на запись.
  Совпадение входа и выхода запрещено даже с -f и -N.

Проверки в WSL:

```
make pr2test
make clipboardtest
make browsertest
```

pr2test создаёт новый тестовый диск, проверяет защищённые переименования,
ошибочные и успешные загрузки, сохранение прежнего содержимого и очистку
временных файлов. Затем настоящий браузер в QEMU получает HTTP-ответы
с задержкой 300 мс перед заголовками и 150 мс между частями тела.
Пользовательский disk.img не изменяется.

На Linux-файловой системе, например в каталоге под /home, также выполняются:

```
make cctest exttest gztest cptest test
```

В тесты gzip добавлены архив с совпадающим FNAME и относительный путь с ..;
в TLS-тесты — POSIX-тайм-аут с продолжением, отменой ожидания и другой ошибкой.
Для host-сборки браузера используется Linux errno через MYOS_HOST_LIBC.
